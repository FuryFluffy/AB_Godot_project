# Reconciled rules — 8 October 2026

These are settled decisions, not questions for another approval round. Corrections have been applied to the affected UI document copies, and both old execution sequences are replaced by the root stage plan.

| Former draft / ambiguous wording | Consolidated rule |
| --- | --- |
| All fight and hotspot leftovers are lost on collection close. | Ordinary room item hotspots, Treasury contents, chests, sachets and caches persist. The existing confirmed-abandonment policy belongs only to post-fight surplus. Reuse the panel with source-specific lifetime. |
| Run Intel may be charged on Explore/launch. | Affordable purchase click immediately deducts Bloom once; cancelled prep does not refund; ownership remains for the pending run; Explore does not charge again. |
| Intel effects and purchase timing are still wholly open. | Approved effects are in the gameplay spec. Permanent counterparts cost 100× one-off price; eligible Passage scales per layer; permanent Submit unlock is included. Exact prices remain configurable/TBD. |
| Field stations merely reuse Refuge crafting menus. | Reuse presentation/transactions with explicit ownership providers: run-only Materials and Backpack outputs in the field; banked Materials and Stash in Refuge. |
| Stations offer only their authored small recipe selection. | All known appropriate recipes may be produced. Authored recipe discoveries expand the permanent library, including after defeat/run end. First-visit materials are granted once. |
| A Rest room offers a subset for the player to choose from. | Spawn 0–1 per layer, assign exactly one of six offers, fixed per room/run; another layer may repeat it. Confirm consumes one use; cancel/revisit preserves it. |
| Rest-room recovery uses the ordinary two-rest counter. | Independent lifecycles: Refuge bed, ordinary two-use HUD Rest, and one-use Rest-room recovery. Preserve each context's preview/cost/recipient rules. |
| Combat rooms contain exploration after the encounter. | Normal/Elite node entry starts combat, victory resolves the node, summary then map. No retreat/exploratory hotspots. Preserve required automatic story sequences and existing defeat losses. |
| Poison/Corruption indicate damage through full-screen fog textures. | Small native Godot particles above the trapped item, reusing the current laptop Light Arrow effect conventions. |
| Map background is a panorama; symbols are flat decorative glyphs. | Revision-2 flat parchment, separate engraved gold raster medallions/state badges, actual graph/routes drawn live. |
| Reusing a castle layout restores old contents/progression. | Retain layout and discovered knowledge; refresh run content/Rest/traps and reset collected/used/Solved state, except permanently dead bosses. |

Frame all gameplay changes around the actual current local implementation. If compatible behavior is already present, verify it. A discrepancy in older code is not authorization to reinstate an obsolete source rule. Report a concrete conflict with current story/loss/ownership integration rather than quietly inventing a new policy.
