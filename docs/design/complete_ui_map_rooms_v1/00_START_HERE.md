# Abyssal Bloom — complete UI, node map and special-room handoff

This is the consolidated 8 October 2026 pack for **one main local Codex chat**. It replaces the two independent execution sequences. It contains corrected Refuge/run UI specifications and their original visuals, the accepted node-map/special-room/Intel rules, and revision-2 map/room art. This is a specification and asset pack, not an implemented Godot patch.

## Start

1. Extract this archive locally next to or outside the existing Godot repository.
2. Give the same Codex chat the separately supplied `CODEX_AB_COMPLETE_UI_MAP_AND_ROOMS_STAGED_PROMPT.md`, inserting the extracted folder's absolute path.
3. Read `01_SCOPE_AND_AUTHORITY.md`, `02_IMPLEMENTATION_STAGES.md`, `03_CONFLICT_RESOLUTION.md` and `04_REVIEW_AND_VERIFICATION.md`, then all relevant detailed source documents.
4. Begin **Stage 00 — audit only**, then stop for Vic's review. Continue one Stage 01–24 at a time after verification/continue instruction.

The fresh prompt is intentionally outside this archive. Old standalone start prompts have been removed so Codex does not start one pack's sequence independently.
